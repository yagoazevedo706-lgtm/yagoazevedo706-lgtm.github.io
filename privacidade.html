Privacy Policy: SBR Videos

Last updated: November 20, 2026

1. YouTube API Services

SBR Videos uses YouTube API Services. By using SBR Videos, you agree to be bound by the YouTube Terms of Service. Google's handling of your data is described in the Google Privacy Policy (http://www.google.com/policies/privacy).

2. What data we access

  • youtube.upload: to upload videos to the user's own channel, set as private with a scheduled publish time.
  • youtube.readonly: to read the channel name once, only to confirm which channel is logged in.

We do not access comments, subscribers, analytics, messages, playlists or any data belonging to other users.

3. How we use, store and share data

  • The OAuth refresh token is stored only on the user's own computer, in a local file. It is never sent to any server other than Google's.
  • The channel name is shown on screen and is not stored.
  • The IDs of uploaded videos are kept in a local log on the same computer so the user knows what was scheduled.
  • We do not sell, share or disclose any user data to third parties, and we do not use it for advertising.
  • The tool does not use cookies or any tracking, and it does not run on any server.

4. How to delete your data and revoke access

  • You can revoke SBR Videos' access to your Google account at any time at https://security.google.com/settings/security/permissions.
  • To delete all stored data, delete the local files youtube-token.json (the token) and agendados.json (the upload log) from the computer.
  • Stored API data is never kept longer than needed: if access is revoked, the token stops working immediately and is no longer used.

5. Changes

If this policy changes, the new version will be posted on this page with a new date.

6. Contact

Questions about this policy: use the contact on the SBR Videos home page or the support e-mail shown on the app's Google consent screen.
